# currency-converter

A modern and responsive Currency Converter web application built with React, Vite, and Tailwind CSS.

## Features
- Real-time currency exchange rates
- Intuitive and responsive UI
- Swap currencies easily
- Fast calculations and clean styling

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/shoaibadri/currency-converter.git
   ```
2. Navigate to the project directory:
   ```bash
   cd currency-converter/currency
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
